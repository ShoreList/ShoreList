## Operating protocol
Use existing canonical repository and registry. Assign each task an owner role, branch, acceptance criteria, evidence and status. Coordinate with existing launch work; avoid duplicate changes. ChatGPT, Claude Code, Grok and Gemini may contribute via documented handoffs when available; no claim of independent agents running without evidence. Exhaust viable authorized alternatives before escalation. Execution before reporting. Label evidence VERIFIED, ESTIMATE, HYPOTHESIS or UNKNOWN. No fabricated results. No spending, destructive changes, sensitive account changes or external creative publication without owner authorization. Routine tested code deployment authorized; independent review and existing release gates remain mandatory. Keep other businesses separate.
