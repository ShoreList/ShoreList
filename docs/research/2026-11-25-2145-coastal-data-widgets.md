## Proposed ADR (HYPOTHESIS)
Shared city-pack API, station/product mapping reviewed per destination, normalized records {cityId, metric, value, unit, kind: observation|prediction|forecast, stationId, sourceUrl, observedAt, fetchedAt, expiresAt, datum, quality}. Store UTC; render local timezone. No precise user location needed for default selected town. Cache by station/product not user. Single-flight requests, bounded retries, stale labels and circuit breaker. Alerts separate from AI; expired or unavailable alert feed never renders all-clear. Widget precomputes tide timeline, shows last updated, opens app for current conditions. No minute-by-minute promise. Proposed TTLs: alerts 2 min subject to provider cache headers, observations 10 min, forecasts 30 min, tide predictions 24h. Validate against actual provider response headers before release.
## Sensitivity (ESTIMATE, not measured)
